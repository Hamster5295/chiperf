# style

本文档规范 Agent 编写代码的风格与规范


## 格式化

Agent 在编写代码时，**不应当** 在写入文件时进行主动格式化，而是 **必须** 在编辑后，通过工具进行 **自动格式化** 工作，以保障项目代码格式硬统一

每一次 Git Commit 之前 **必须** 执行格式化


## 注释

Agent 应当在 **复杂逻辑** 处添加 **简洁** 的注释。  

注释应当
1. 若代码**功能**复杂：描述 **代码的意图和目标**，必须从全局、架构的视角描述，不描述实现细节。
2. 若代码**算法**复杂：概述算法的**原理**


## 限制与边界

Agent 应当且仅应当 **按照用户指令** 修改代码，**禁止** 修改用户指令以外的代码。

若在代码编辑中发现先前未发现，或未修复的 Bug 和其他问题，应当最终向用户指出，不得直接修改。
