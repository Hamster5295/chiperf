# chiperf 可视化前端

**产物是两个文件**（`bun run build` 生成到仓库根的 `dist/`）：

| 产物 | 说明 |
| --- | --- |
| `dist/index.html` | **独立单文件页面**：CSS 与 JS 全部内联，双击即可打开，也可以直接丢到任意静态托管 |
| `dist/app.js` | **HTTP 服务器**：可执行（带 shebang），启动后对外提供上面那个页面 |

`app.js` 取页面的优先级：`--html <路径>` → **与 app.js 同目录的 `index.html`**（默认，改完源码 `bun run build` 后刷新即可，不必重启服务）→ 构建时内嵌的副本（把 `app.js` 单独拷到别的机器也能跑，测试里有断言）。启动日志会打印实际用的来源。

```bash
cd src/frontend
bun install
bun run build        # → ../../dist/index.html + ../../dist/app.js

bun ../../dist/app.js                 # http://127.0.0.1:4173
bun ../../dist/app.js -p 8080         # 换端口
bun ../../dist/app.js --host 0.0.0.0  # 对外网卡开放（会列出可访问地址）
bun ../../dist/app.js --html x.html   # 改为提供外部页面文件
bun ../../dist/app.js --help
```

页面里的解析与可视化全部在浏览器里跑：文件不上传、不发任何请求（构建时断言过产物**不引用任何外部资源**）。

## 视图

| 视图 | 内容 |
| --- | --- |
| 总览 | 周期/时间跨度、事件数、B/记录、追踪对象、在飞条目、平均延迟、气泡、诊断；记录类型分布；每周期事件数；时钟域表；元数据；各轨道延迟 |
| 时间轴 | **时钟-流水线图**：**时钟**、**状态机**（每段驻留一个六边形，切角处即状态切换）、**流水线**（六边形条目；冲刷条目空心斜纹 + 虚线框；气泡虚线框）、**数值**（波形/折线/六边形块三种模式）、**事件**（evt + 消息 + 异步记录）五类行；横轴**只有周期数**；行加高留白、行头只留名称（配色区分分组）、可**拖拽排序**；数值默认按 hex 显示；行头与画布边线之间留出内边距；悬停给「周期所在整列」加浅色高光；`Ctrl/⌘ + 滚轮` 缩放；网格线画在波形**之下** |
| 流水线 | 气泡统计与区间列表、占用度曲线、延迟直方图、跨域条目、条目明细表 |
| 状态机 | 每台状态机**一个独立大框**：状态占用比例（格子 + 占比）、该状态机自己的状态时序色带、**状态转移图**（圆 = 状态、箭头 = 方向、箭头颜色 = 频度、自环绕节点、边标次数；由相邻两条 `fsm` 记录推断） |
| 计数器 | 累计曲线、每周期增量、终值占比饼图、区间差/比率工具（`delta_between`）；横轴为**该计数器所在域的周期数** |
| 数值 | 保持型阶梯波形（`x`/`z` 空心标记）、字符串值事件条、变化事件列表；横轴为**该数值所在域的周期数** |
| 表格 | 智能表格：8 类数据集、排序、搜索、列开关、虚拟滚动、行详情、CSV 导出 |

## 规范相关的可视化约定

- **`async=1` 的事件画在两个时钟沿之间**（区间内部），不吸附到沿刻度上，并用空心/虚线样式区分（spec §6.7）。
- **占用度是半开区间** `[enter, close)`：同周期进出的条目延迟为 0 且不占任何周期（spec §9.4）。
- **未闭合条目**画成虚线到该轨道最后一个周期，**不伪造退出**（spec §10.5）。
- **跨域条目**不给周期延迟：显示两端位置，并在两域都声明了 `period` 时给 `latency_time`（spec §6.5 / §9.4）。
- **诊断不隐藏**：语义异常（凭空出队、负计数、自环、重复标记、域拼写错误…）在头部显示数量并可展开逐条查看（spec §10.4）。
- **所有视图的横轴都是周期数**（时间轴一概不画）：每条轨道/计数器卡片跟的是它自己时钟域的周期号（`mem#6 ≠ default#6`），多域并排时标 ns 会被误读成同一条时间轴。
- 具体时刻不丢，只是退到该在的地方：悬停标签给「周期 N · X ns」，跨域延迟仍以 `latency_time` 给出（两域都声明了 `period` 时）。
- 悬停用「整列浅色高光 + 当前行加深」表示，不画竖向虚线。
- 数值行**没有记录的周期按保持处理**：首个采样之前用更淡的实线补出（推断段）、最后一个采样之后保持到画布右边，线不断开；变化处画传统波形图那样的「X」。
- **默认按 hex 显示**数值（位向量是 RTL 的常态）。
- 在行上**右键**打开菜单（靠近视口底部时自动向上翻，菜单比视口高时可滚动）：数值行给「显示格式（`dec`/`hex`/`oct`/`bin`，32 位以内还有 `rv32`/`rv64`，按 RISC-V 指令译码见 `src/rv.ts`）+ 显示模式」；流水线行给「显示格式」（作用于条目标记 tag）；时钟/事件行没有可配置项。菜单点击外部或 Esc 关闭。
- 数值行三种显示模式：**波形**（保持型阶梯，两端补出、线不断开）、**折线**（直接连采样点看趋势）、**六边形块**（每段一个值、块内写值、一律竖直居中，与流水线同一视觉语言）。
- 六边形上的字色按**真实画布底色**判定（跟着深浅主题走：向上合成 DOM 背景色，不假定白底），并支持"该处不填充则直接看底色"。
- 数值行的**六边形块**模式只画块、不画采样点（块的边界即采样位置，块内已写着值）。
- 流水线条目与数值块都画成**六边形**：两端切角正好落在相邻条目的交界处，数值跳变一眼可见。六边形上的数值**加粗**，并按底色明度自动取黑字或白字（半透明填充先与白底混色再判明度）。
- 流水线的**气泡**（该级本周期无在飞内容）画成六边形空心虚线。**冲刷（X）条目**不填充，用"空心 + 斜纹 + 同一套虚线框"表示：与气泡一样是空心虚线，靠红色斜纹区分"这本该有内容、但被冲掉了"。
- 冲刷条目的标记文字按空心底色取深色（十六进制底色判定只对实色条目生效）。
- 域内只插了上升沿（文件里只有 `[clk] p`）时，时钟泳道按相位模型把下降沿补在**周期中点**，画成完整方波；悬停会注明"下降沿由相位模型补出"，`n` 记录数统计不受影响。
- 缩放不设上下限：`Ctrl/⌘ + 滚轮`（锚点=指针处周期）与工具栏 `−`/`+` 可以一直放大缩小；只有「画布总宽 200k px」的渲染保险会兜底，工具栏读数始终显示**实际**比例。
- 状态机的最后一个状态驻留不可确定（spec §9.5），卡片里用虚线描边标注"未定型"。
- 时间轴上的状态机泳道：每个状态驻留段是**六边形**（与流水线条目同一形状语言），段内写状态名、加粗并按底色判黑/白；最后一段驻留不可确定 → 浅色虚线的开放六边形。

## 结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 单文件页面**模板**（构建时把两个占位注释替换成内联 CSS/JS） |
| `build.ts` | 构建：打包浏览器端 → 内联成 `dist/index.html`；打包 `server.ts` 并把页面 base64 内嵌 → `dist/app.js` |
| `inline.ts` | 内联逻辑（含 `</script>` 硬化），可单测 |
| `server.ts` | HTTP 服务器源码（bun `--html`/`-p`/`--host`/`-q`/`-h`） |
| `styles.css` | 样式（浅色 + 跟随系统深色） |
| `src/main.ts` | 入口：视图注册表 + 启动 |
| `src/app.ts` | 外壳：文件加载（含 gzip）、导航、工具栏、选中总线、详情抽屉、诊断面板 |
| `src/view.ts` | 视图契约（`View` / `ViewContext` / `Selection`）与格式化 |
| `src/charts.ts` | 纯 SVG 图表工具（比例尺、刻度、路径、配色、提示、卡片） |
| `src/sample.ts` | 内置示例轨迹生成器（双时钟域 + 5 级流水 + 异步中断） |

启动时**不自动载入**任何轨迹：先显示「把 .chiperf 拖到这里 + 打开 .chiperf / 载入示例」的欢迎页（拖拽全页可用，文件只在本地解析）。
| `src/views/*.ts` | 7 个视图 |
