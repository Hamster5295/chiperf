# chiperf 可视化前端

**产物是两个文件**（`bun run build` 生成到仓库根的 `dist/`）：

| 产物 | 说明 |
| --- | --- |
| `dist/index.html` | **独立单文件页面**：CSS 与 JS 全部内联，双击即可打开，也可以直接丢到任意静态托管 |
| `dist/app.js` | **HTTP 服务器**：可执行（带 shebang），启动后对外提供上面那个页面 |

`app.js` 取页面的优先级：`--html <路径>` → **与 app.js 同目录的 `index.html`**（默认，改完源码 `bun run build` 后刷新即可，不必重启服务）→ 构建时内嵌的副本（把 `app.js` 单独拷到别的机器也能跑，测试里有断言）。启动日志会打印实际用的来源。

```bash
cd src/frontend
bun install
bun run build        # → ../../dist/index.html + ../../dist/app.js

bun ../../dist/app.js                 # http://127.0.0.1:4173
bun ../../dist/app.js -p 8080         # 换端口
bun ../../dist/app.js --host 0.0.0.0  # 对外网卡开放（会列出可访问地址）
bun ../../dist/app.js --html x.html   # 改为提供外部页面文件
bun ../../dist/app.js --help
```

页面里的解析与可视化全部在浏览器里跑：文件不上传、不发任何请求（构建时断言过产物**不引用任何外部资源**）。

## 视图

| 视图 | 内容 |
| --- | --- |
| 总览 | 周期、事件数、B/记录、追踪对象、在飞条目、平均延迟、气泡、诊断；记录类型分布；每周期事件数；时钟表；元数据；各轨道延迟 |
| 时间轴 | **时钟-流水线图**：**时钟**、**状态机**（每段驻留一个六边形，切角处即状态切换）、**流水线**（六边形条目 = 该级连续持有同一个值的那一段；未闭合虚线框；气泡虚线框）、**计数器**（累计值，默认折线）、**数值**（默认六边形块：连续同值的采样并成**一个**六边形，值标一次；另有波形/折线）、**事件**（evt + 消息 + 异步记录）六类行；横轴**只有周期数**；行加高留白、行头左端是名称、右端用浅色文字标出该行的记录类型（时钟 / 状态机 / 流水线 / 计数器 / 数值 / 事件）、可**拖拽排序**；数值默认按 hex 显示；行头与画布边线之间留出内边距；悬停给「周期所在整列」加浅色高光；`Ctrl/⌘ + 滚轮` 以指针处为锚点缩放（**不设上限**）、横向滚轮或 `Shift+滚轮` 平移，缩到最小时整条轨迹横向铺满可视宽度；网格线画在波形**之下** |
| 流水线 | 概览（流水级/在飞条目/占用率/最长气泡）+ **每个流水级一张大方框**，框内三项指标：饼图给「有内容 vs 空泡」比例；横向柱状图给**延迟分布**；横向柱状图给**连续空泡段长度分布**（8 个气泡周期是「2 段 1 拍 + 2 段 3 拍」还是「8 段 1 拍」，饼图看不出差别，这张图看得出）。两张分布图都按次数取前 10、每根柱颜色不同，并列出中位/平均/方差/标准差/范围/样本数 |
| 状态机 | 每台状态机**一个独立大框**：状态占用比例（格子 + 占比）、该状态机自己的状态时序色带、**状态转移图**（圆 = 状态、箭头 = 方向、箭头颜色 = 频度、自环绕节点、边标次数；由相邻两条 `fsm` 记录推断） |
| 计数器 | 累计曲线、每周期增量、终值占比饼图、区间差/比率工具（`delta_between`）；**`[evt]` 轨按「每条 +1」折算成计数器一起展示**（显示名带 `[evt]` 前缀、键带 `evt:` 前缀，同名 `[cnt]`/`[evt]` 是两条轨）；每张图**窗口式**缩放/平移：`Ctrl/⌘ + 滚轮` 以指针处为锚点缩放、横向滚轮或 `Shift+滚轮` 平移；初始即整条铺满，最小 = 铺满（不能更小）、最大不限；缩放过小时 `[evt]` 折算轨画成**每周期事件频率密度带**（越密越深）；横轴为**周期数**；时间轴里也有一条计数器泳道（默认折线） |
| 数值 | 保持型阶梯波形（`x`/`z` 空心标记）、字符串值事件条、变化事件列表；每张图同样是**窗口式**缩放/平移（初始铺满、最小铺满、最大不限），缩放过小时数值轨退化成**折线**（纵轴取中间 90% 分位当上下界，极端 10% 贴边 clamp，避免离群值压扁趋势）、不可坐标化的轨退化成**密度带**；整数轨的**纵坐标按 hex 写**（`0x…`）；横轴为**周期数** |
| 表格 | 智能表格：8 类数据集、排序、搜索、列开关、虚拟滚动、行详情、CSV 导出 |

## 规范相关的可视化约定

- **`async=1` 的事件画在两个时钟沿之间**（区间内部），不吸附到沿刻度上，并用空心/虚线样式区分（spec §6.5）。
- **占用度是半开区间** `[enter, close)`：同周期进出的条目延迟为 0 且不占任何周期（spec §9.4）。
- **未闭合条目**画成虚线到该轨道最后一个周期，**不伪造退出**（spec §10.5）。
- **条目延迟是周期差**：`close - enter`，未闭合条目不参与（spec §9.4）。
- **`[rst]` 系统复位**（规范 §7.8）：复位前的事件记录在解析期就被丢弃，视图里看不到复位本身，只有头部一个信息 chip（`复位 ×1（已丢弃前 8 条）`）说明"文件前面为什么少了一截"。
- **`[evt]` 在计数器页按「每条 +1」折算**（spec §9.1）：事件记录只有「发生过」这一个信息，所以计数是确定的 —— 一条记录一次 +1，每周期增量 = 该周期的事件条数；折算放在解析器（`eventCounters`），视图只管画。
- **诊断不隐藏**：语义异常（负计数、重复计数…）在头部显示数量并可展开逐条查看（spec §10.4）。
- **所有视图的横轴都是周期数**：v1.0 只有一条时间轴（`clock`），不做时间换算。
- 悬停标签给「周期 N」，不显示时刻。
- 悬停用「整列浅色高光 + 当前行加深」表示，不画竖向虚线。
- 数值行**没有记录的周期按保持处理**：首个采样之前用更淡的实线补出（推断段）、最后一个采样之后保持到画布右边，线不断开；变化处画传统波形图那样的「X」。
- **界面上叫「警告」，规范里叫"诊断"**（§10.4 的诊断码 / 诊断表）：头部 chip、右侧抽屉、总览统计、表格视图的按钮都用「警告」；解析器与规范里的字段名（`diagnostics`）不变。头部 chip 的位置就在「N 周期」右边，用橙黄色（`--warn`）提示。
- **全局时钟（`clock`）用绿色**：与波形查看器的习惯一致。
- 行头左键三种手势：普通=只选它（多选之后点其中一行即收窄成那一行）、**Shift**=连选一整片、**Ctrl/⌘**=增减点击的那一行；Esc 取消，换文件清空。按下时不动选中、松开成为点击才收窄，所以**拖动仍能搬走整块**（拖动后浏览器若补一个 click 会被吃掉）。
- 批量操作：拖动选中行中的任意一个 → **整块移动**（块内相对顺序不变）；右键选中的行 → 菜单作用于整批（标题写明会改到几行、跳过几行不适用），隐藏也支持整批。
- **批量改设置只碰"适用"的行**：显示格式只作用于有格式的行（数值/计数器/流水线），显示模式只作用于有显示模式的行（数值/计数器）—— 时钟、事件这类没有显示方式的行不会被批量操作改到。
- **默认按 hex 显示**数值（位向量是 RTL 的常态）。
- 在行上**右键**打开菜单（靠近视口底部时自动向上翻，菜单比视口高时可滚动）：数值行给「显示格式（`dec`/`hex`/`oct`/`bin`，位宽够时还有 `rv32`/`rv64` 按 RISC-V 指令译码见 `src/rv.ts`，rv32 要求 ≤32 位、rv64 ≤64 位）+ 显示模式」；流水线行给「显示格式」（作用于条目标记 tag）；时钟/事件行没有可配置项。菜单点击外部或 Esc 关闭。
- **行可右键隐藏**，波形图左上角的 **"+"** 把隐藏的行显示回来（有隐藏时带数量，点开列出被隐藏的行，多于一条给「全部显示」）；隐藏只记在内存里，拖拽顺序仍保留。
- 数值行三种显示模式：**波形**（保持型阶梯，两端补出、线不断开）、**折线**（直接连采样点看趋势）、**六边形块**（每段一个值、块内写值、一律竖直居中，与流水线同一视觉语言；**数值行的默认**）。
- 低缩放（每周期像素很低）时，数值/计数器行**忽略显示模式**，统一按每列保持值连成一条**折线**看趋势（不画填充块）；数值折线的纵轴取中间 90% 分位当上下界、极端值贴边 clamp（计数器仍用全量范围），避免个别离群采样把整条趋势压扁；流水线行只有两种要素：**有值**按行色着色、**气泡**作为橙色叠加层（只要该列有气泡就叠加；透明度由**该列气泡段的长度**决定：短于淡出阈值的气泡段完全不透明，达到阈值的气泡段淡出为 `BUBBLE_FILL`（0.08）—— 这样紧凑流水线里的偶发气泡醒目，而启动-休息型轨道两段工作区间之间的长空闲段不抢视线、降低视疲劳）；不再按条目取值着色；事件行则按出现频率画成条带，频率越高越不透明。放大回到全量模式后再恢复所选模式、按取值着色与三角标记。
- 波形图下方有「气泡淡出（低缩放）」卡片：设置阈值 x（周期，默认 64）后，长度 ≥ x 的气泡段在低缩放下淡出为 `BUBBLE_FILL`，更短的保持全不透明（只影响低缩放，便于在"紧凑流水线要看气泡"与"启动-休息型轨道不想被长空闲段晃眼"之间取舍）。
- 六边形上的字色按**真实画布底色**判定（跟着深浅主题走：向上合成 DOM 背景色，不假定白底），并支持"该处不填充则直接看底色"。
- 数值行的**六边形块**模式只画块、不画采样点（块的边界即采样位置，块内已写着值）。
- 流水线条目与数值块都画成**六边形**：两端切角正好落在相邻条目的交界处，数值跳变一眼可见。六边形上的数值**加粗**，并按底色明度自动取黑字或白字（半透明填充先与白底混色再判明度）。
- 时间轴里**实色内容块**（流水线条目、状态机状态段、数值/计数器块）的填充统一为 **60%** （`BLOCK_FILL`），边框/虚线不受影响；空心与推断类标记保持"更淡"：气泡 8%、推断段 15%、未闭合条目空心。填充变淡后标记文字按底色判黑/白，实测 88 个标签对比度最低 8.1:1。
- 流水线条目**按取值着色**（同一条指令在 IF/ID/EX/MEM/WB 里同色，顺着颜色能把它跟到写回）：颜色键只看数值本身，位向量取十进制（`16'h9117` 与 `32'h9117` 同色），换进制/换宽度都不变色；没有取值的条目退回轨道色。
- 条目上的数值文本按**每条泳道**各有一份额度（`TAG_BUDGET`）：整张图共用一份时，靠前的泳道会把额度吃光、后面的泳道一个字都画不出来。
- 流水线的**气泡**（该级本周期为空）画成六边形空心虚线。`[pip]` 是保持型取值后没有"冲刷（X）"这种独立状态：冲刷就是"该级被设成 `bubble`"，与正常离开在数据上不可区分（spec §12.5）—— 图上也一样画成气泡。
- 只插了上升沿（文件里只有 `[clk] p`）时，时钟泳道按相位模型把下降沿补在**周期中点**，画成完整方波；悬停会注明"下降沿由相位模型补出"，`n` 记录数统计不受影响。
  只有视口大小的纹理意味着内存与绘制开销与全图宽度无关；左上角 chip 显示实际走的是「Canvas2D」还是「SVG」（画布出错时整体退回 SVG 并重画）。
  形状坐标是"绘图坐标系"，滚动只改 `scene.offset`，顶点数据不重打包。
  时间轴是**窗口式**：画布宽度就是可视宽度，缩放改变的是"窗口覆盖多少周期"（不是把一个超宽画布滚来滚去），所以放大没有上限、缩小到整条轨迹铺满为止；平移用横向滚轮/`Shift+滚轮`。
  载入时**分片画且画完才揭开**（看不到半成品）；缩放/平移只更新比例尺并**原地重画**轴、网格与泳道（不动滚动容器，也不会把半成品露出来）。
  低缩放只画**轮廓**（逐像素聚合，不碰全量数据）；放大后按可见窗口**二分读取**，只 materialize 看得见的那一段（流水线条目、状态机区段、数值采样都一样），窗口外的数据不建节点。
  形状坐标乘 DPR 变成设备像素；**滚动只改 `scene.offset`**（着色器里减掉），顶点数据不重打包 —— 横向拖动的开销与全图宽度无关。
  画布**不能**按整幅图开：绘图区动辄几万像素宽，而 GPU 纹理边长通常只有 8k~16k，超限会让整条管线校验失败、什么都不画
  （Canvas2D 不挑尺寸，所以只有 GPU 路径会暴露这个问题）。画布绘制抛错时整体退回 SVG 并重画一次。
- **波形上可以打标记（最多两个）**：在波形里右键 → 「在此处加标记」；拖动手柄调整位置，右键手柄可删除。
  两个标记之间的区间就是**流水线**与**状态机**统计的范围（闭区间、按周期）。
  口径：条目按"与区间**相交**"计入，气泡段按"落在区间里的那部分"计长 —— 相关函数在解析器里
  （`itemsWithin` / `latencyStats(track, range)` / `bubbleStats(track, range)`），视图只负责调用。
  拖拽期间**只动视觉**，松手才提交 ⇒ 只重算一次；重算本身按片让出主线程（`chunk.ts`），不阻塞交互。
- 缩放**没有上限**：`Ctrl/⌘ + 滚轮`（锚点=指针处周期）与工具栏 `−`/`+` 可以一直放大到看清单个周期；下限就是整条轨迹刚好铺满可视宽度（再往外缩会被夹住）。工具栏读数显示当前 px/周期、可见周期数与总周期数。低缩放只画**轮廓**（逐像素聚合），放大后按窗口读取细节，节点数始终被预算钉住。
- 状态机的最后一个状态驻留不可确定（spec §9.5），卡片里用虚线描边标注"未定型"。
- 流水线视图按**流水级**（`pip` 轨道）分组，每级一个方框**三项指标**（`[pip]` 是保持型取值，一条轨道同时只有一个条目）：
  - **占用/空泡饼图**（空泡沿用时间轴的橙色）；
  - **延迟分布**：只统计已结束条目，中位/平均/方差/标准差/范围/样本数来自 `latencyStats`（§9.4 派生层）；
  - **连续空泡段长度分布**：统计每段空泡有多长（`bubbleStats` ← `track.bubbleRanges`），与「有多少个气泡周期」（`bubbles.length`）互补 —— 同一批数据的两种切法。
  两张分布图共用一套渲染：按出现次数取前 10、柱色冷→暖各不相同、最多的一档加描边；数值来自 `describeSamples`（总体口径：中位数偶数取中值、方差除以 n）。
- **保持型的"尾巴"一律画到轨迹末尾**：状态机的最后一段状态、未闭合的流水线条目、以及末尾"无内容"的气泡，都延续到**轨迹的末周期**（不是画布右边缘——此后再无记录，画出去就是编造数据）。推断出来的部分用更淡/虚线的开放样式，提示里注明是推断。
- 时间轴上的状态机泳道：每个状态驻留段是**六边形**（与流水线条目同一形状语言），段内写状态名、加粗并按底色判黑/白；最后一段驻留不可确定 → 浅色虚线的开放六边形。

## 结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 单文件页面**模板**（构建时把两个占位注释替换成内联 CSS/JS） |
| `build.ts` | 构建：打包浏览器端 → 内联成 `dist/index.html`；打包 `server.ts` 并把页面 base64 内嵌 → `dist/app.js` |
| `inline.ts` | 内联逻辑（含 `</script>` 硬化），可单测 |
| `server.ts` | HTTP 服务器源码（bun `--html`/`-p`/`--host`/`-q`/`-h`） |
| `styles.css` | 样式（浅色 + 跟随系统深色） |
| `src/main.ts` | 入口：视图注册表 + 启动 |
| `src/app.ts` | 外壳：文件加载（含 gzip）、导航、工具栏、选中总线、详情抽屉、诊断面板 |
| `src/view.ts` | 视图契约（`View` / `ViewContext` / `Selection`）与格式化 |
| `src/charts.ts` | 纯 SVG 图表工具（比例尺、刻度、路径、配色、提示、卡片） |
| `src/rv.ts` | 数值显示格式与 RISC-V 指令译码：**RV64GC**（RV32I/RV64I + M/A/F/D/C，压缩指令按低两位自动识别）＋ **Zicsr**（含 CSR 名表与区间名）、Zifencei、Zba/Zbb/Zbc/Zbs、Zicond、Zfh，以及 **V**（RVV 1.0：配置、整数/定点/浮点算术、掩码/归约/搬移/转换与各类向量访存） |
