# chiperf 可视化前端

**产物是两个文件**（`bun run build` 生成到仓库根的 `dist/`）：

| 产物 | 说明 |
| --- | --- |
| `dist/index.html` | **独立单文件页面**：CSS 与 JS 全部内联，双击即可打开，也可以直接丢到任意静态托管 |
| `dist/app.js` | **HTTP 服务器**：可执行（带 shebang），启动后对外提供上面那个页面 |

`app.js` 取页面的优先级：`--html <路径>` → **与 app.js 同目录的 `index.html`**（默认，改完源码 `bun run build` 后刷新即可，不必重启服务）→ 构建时内嵌的副本（把 `app.js` 单独拷到别的机器也能跑，测试里有断言）。启动日志会打印实际用的来源。

```bash
cd src/frontend
bun install
bun run build        # → ../../dist/index.html + ../../dist/app.js

bun ../../dist/app.js                 # http://127.0.0.1:4173
bun ../../dist/app.js -p 8080         # 换端口
bun ../../dist/app.js --host 0.0.0.0  # 对外网卡开放（会列出可访问地址）
bun ../../dist/app.js --html x.html   # 改为提供外部页面文件
bun ../../dist/app.js --help
```

页面里的解析与可视化全部在浏览器里跑：文件不上传、不发任何请求（构建时断言过产物**不引用任何外部资源**）。

## 视图

| 视图 | 内容 |
| --- | --- |
| 总览 | 周期/时间跨度、事件数、B/记录、追踪对象、在飞条目、平均延迟、气泡、诊断；记录类型分布；每周期事件数；时钟域表；元数据；各轨道延迟 |
| 时间轴 | **时钟-流水线图**：只保留**时钟**、**流水线**（完成/冲刷/未闭合）、**事件**（evt + 消息 + 异步记录，合并在一组）三类行；共享横轴、可缩放、**行头可拖拽排序**（顺序在本次会话内保持），行头背景色区分分组；悬停高亮「鼠标所在行 + 该行时钟域的当前周期」并给出域/周期/时间 |
| 流水线 | 气泡统计与区间列表、占用度曲线、延迟直方图、跨域条目、条目明细表 |
| 状态机 | 每台状态机**一个独立大框**：状态占用比例（格子 + 占比）、该状态机自己的状态时序色带、**状态转移图**（圆 = 状态、箭头 = 方向、箭头颜色 = 频度、自环绕节点、边标次数；由相邻两条 `fsm` 记录推断） |
| 计数器 | 累计曲线、每周期增量、终值占比饼图、区间差/比率工具（`delta_between`） |
| 数值 | 保持型阶梯波形（`x`/`z` 空心标记）、字符串值事件条、变化事件列表 |
| 表格 | 智能表格：8 类数据集、排序、搜索、列开关、虚拟滚动、行详情、CSV 导出 |

## 规范相关的可视化约定

- **`async=1` 的事件画在两个时钟沿之间**（区间内部），不吸附到沿刻度上，并用空心/虚线样式区分（spec §6.7）。
- **占用度是半开区间** `[enter, close)`：同周期进出的条目延迟为 0 且不占任何周期（spec §9.4）。
- **未闭合条目**画成虚线到该轨道最后一个周期，**不伪造退出**（spec §10.5）。
- **跨域条目**不给周期延迟：显示两端位置，并在两域都声明了 `period` 时给 `latency_time`（spec §6.5 / §9.4）。
- **诊断不隐藏**：语义异常（凭空出队、负计数、自环、重复标记、域拼写错误…）在头部显示数量并可展开逐条查看（spec §10.4）。
- 多域同屏时横轴是**各域自己的周期号**（`mem#6 ≠ default#6`），工具栏会提示；需要统一时刻就把"时间轴"打开（要求域声明 `period`/`freq`）。
- 时间轴的悬停高亮刻意**不画横跨全图的吸附竖线**：跨域时那样会让人误读成"全局同一时刻"，改成只在鼠标所在行高亮该行时钟域的周期。
- 状态机的最后一个状态驻留不可确定（spec §9.5），卡片里用虚线描边标注"未定型"。

## 结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 单文件页面**模板**（构建时把两个占位注释替换成内联 CSS/JS） |
| `build.ts` | 构建：打包浏览器端 → 内联成 `dist/index.html`；打包 `server.ts` 并把页面 base64 内嵌 → `dist/app.js` |
| `inline.ts` | 内联逻辑（含 `</script>` 硬化），可单测 |
| `server.ts` | HTTP 服务器源码（bun `--html`/`-p`/`--host`/`-q`/`-h`） |
| `styles.css` | 样式（浅色 + 跟随系统深色） |
| `src/main.ts` | 入口：视图注册表 + 启动 |
| `src/app.ts` | 外壳：文件加载（含 gzip）、导航、工具栏、选中总线、详情抽屉、诊断面板 |
| `src/view.ts` | 视图契约（`View` / `ViewContext` / `Selection`）与格式化 |
| `src/charts.ts` | 纯 SVG 图表工具（比例尺、刻度、路径、配色、提示、卡片） |
| `src/sample.ts` | 内置示例轨迹生成器（双时钟域 + 5 级流水 + 异步中断） |
| `src/views/*.ts` | 7 个视图 |

```bash
bun test            # 产物契约测试：先构建，再起服务断言路由/内容/自包含
bunx tsc --noEmit
```
