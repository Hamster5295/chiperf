# 这是什么？


Chiperf 是一种用于 **硬件微架构状态可视化** 的文件格式。  
对于任何 **支持输出该格式** 的硬件仿真器，其产出均可输出标准解析器，生成可视化结果。

如图是一个 6 级流水线 CPU 执行 Coremark 单周期产出的可视化过程。  
其内部流水气泡(橙色条带状图样)、`pc`, `sp` 等重要指针、分支预测结果与频次均可见。

![基于 Chiperf 生成的可视化波形图](/waveform.avif)


## 简单来说...

Chiperf 提出了一种 ***标准的 RTL 插桩格式***。

> [!NOTE]
> "插桩"，即在程序执行时**输出关键信息**，用于分析 / 调试。
>
> 例如，你可以在 CPU 的 RTL 代码中每个时钟周期输出一次 `pc` 值，追踪 CPU 当前的运行位置。该过程即为**插桩**。

如果 RTL / 仿真器能按照 Chiperf 标准插桩输出，则使用不同仿真工具的不同 RTL 项目可以**复用同一套工具**进行可视化调试、性能分析、横向对比等工作。


## 他长啥样？

一个简单的 Chiperf 文件长这样：

```chiperf
chiperf 1.0
@meta design="example" note="一个简单的 3 段流水 CPU"

# ---- 周期 1 ----
[clk] p
[evt] "Cache Miss"
[val] "PC", 0x800001d0
[pip] "IF", 0x1234abcd
[pip] "EX", bubble
[pip] "WB", bubble

# ---- 周期 2 ----
[clk] p
[evt] "Cache Hit"
[val] "PC", 0x800001d4
[pip] "IF", 0x4321abdc
[pip] "EX", 0x1234abcd
[pip] "WB", bubble

# ---- 周期 2 ----
[clk] p
[evt] "Cache Hit"
[val] "PC", 0x800001d8
[pip] "IF", 0xffeeddcc
[pip] "EX", 0x4321abdc
[pip] "WB", 0x1234abcd
[cnt] "Write Back"

@end
```
该文件格式足够友好，人类即可阅读。

## 图从哪来？

在上文中，我列出了 2 个不同的波形图，他们自不同的 Chiperf 文件生成。

事实上，Chiperf ***本身只是一个文件格式***，并不自带生图功能。上述的波形图均由另行开发的 Chiperf 文件解析器与可视化器生成。该解析器与可视化器均存放在本仓库中。

Chiperf 的规范文件**按版本更新**，因此您可以自由基于某个特定版本，或若干兼容版本开发对应的软件解析器与格式化器，以实现特定需求下的二次处理或可视化工作。


## 使用流程

一个完整的 Chiperf 使用流程如下：


### 1. RTL / 仿真器插桩

在 RTL 代码，或仿真器中插入监控函数，在特定行为 (时钟上升沿，寄存器变化，etc.) 发生时，向文件输出符合 Chiperf 标准的事件行 / 字段。


### 2. 运行仿真

在指定工作负载 (程序) 下运行仿真，得到完整 (或不完整，Chiperf 支持损坏恢复) 的 Chiperf 文件。


### 3. 解析与可视化

使用一个已有的解析器 & 可视化器，或根据需求自主编写相应工具，加载上述得到的 Chiperf 文件进行调试 / 性能分析工作。
