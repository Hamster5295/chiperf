# 事件总览

事件是 Chiperf 的核心。本章节将描述事件的基本格式、共同特征与选型。


## 语义速查

| 类型            | 语义     | 参数               | 特殊属性 | 描述                 |
| --------------- | -------- | ---------------------- | -------- | ---------------------- |
| [`clk`](clk.md) | 推进时间 | `<边沿>`               | ——       | `p` = 一个周期         |
| [`cnt`](cnt.md) | 累加     | `<名称>[, <增量>]`     | `abs=`   | 又发生了一次           |
| [`val`](val.md) | **保持** | `<名称>, <值>`         | ——       | 这个信号现在是多少     |
| [`pip`](pip.md) | **保持** | `<名称>, <值\|bubble>` | ——       | 这一级现在装着什么     |
| [`fsm`](fsm.md) | **保持** | `<名称>, <状态>`       | ——       | 状态机现在在哪儿       |
| [`evt`](evt.md) | 瞬时     | `<名称>[, <值>]`       | ——       | 发生了一件事（带载荷） |
| [`msg`](msg.md) | ——       | `<行尾文本>`           | ——       | 给人看的一句话         |
| [`rst`](rst.md) | 控制     | 无                     | ——       | 之前的记录不要了       |


## 共同特征

### 基本格式

```
[ <事件类型> ] <参数...> [ , <属性>... ] [ # 注释 ]
```


事件应当满足：
- **一条记录一行**，不许跨行；行尾必须有 `\n`。
- 参数在前、属性在后，否则将视为非法行跳过。
- 注释必须与内容 **间隔至少一个空格**。
- 未知处理：
    - 未知的 `[类型]` 将被跳过该行并计数
    - 未知的 `@指令` 将被跳过
    - 未知的 **属性** 将被跳过。
- v1.0 只有**一个全局时钟** `clock`，没有时钟域

### 名字与轨道标识

每个事件类型各自维护一套轨道，**轨道标识是 `(事件类型, 名字)`**（工具链内部通常写作 `<类型>:<名字>`，如 `val:core.ipc`、`fsm:core.ctrl`、`pip:core.if`）。

- 同一个名字 **可以** 同时出现在 `cnt`/`val`/`fsm`/`evt`/`pip` 等不同类型上：它们是**不同轨道**，互不干扰。
- 解析器与可视化 **不会** 因为重名而自动改名、去重或合并。名字字符串原样保留。
- 同一类型内部，同名即同一条轨道（例如两条 `[val] "x", …` 属于同一条数值轨）。

### 通用属性

| 属性     | 值                               | 作用                                                               |
| -------- | -------------------------------- | ------------------------------------------------------------------ |
| `at=`    | `int[p\|n]`，如 `42p`、`7n`、`9` | **显式指定某个事件发生的周期**                                     |
| `async=` | `0` / `1`                        | 异步事件标志。标记后，该事件将不会被绘制成与时钟对齐(仅视觉效果)。 |
| `note=`  | 字符串                           | 人类可读注解；对派生量没有影响                                     |

> [!WARNING]
> 若非必要，请尽量减少使用 `at`, 这会打乱文件的固有顺序，降低可读性。

### 数值

每种记录的第 2 个参数（或载荷）都是"值"，五种写法：

| 写法                                | 类型   | 例                                                     |
| ----------------------------------- | ------ | ------------------------------------------------------ |
| 十进制整数                          | `int`  | `1234`、`-1`                                           |
| 其它进制整数                        | `int`  | `0x1f`、`0b1010`、`0o17`                               |
| Verilog 字面量（可带宽度与 4 态位） | `bits` | `32'h8000_01d0`、`4'b10xz`、`8'hFF`                    |
| 实数                                | `real` | `0.95`、`1.2e-3`                                       |
| 字符串                              | `str`  | `"addi a0,a0,1"`（5 种转义：`\"` `\\` `\n` `\t` `\r`） |
| 裸词符号                            | `sym`  | `IDLE`、`FETCH`、`core.if`                             |

- 小写裸词 `x` / `z` 单独出现时是 **4 态标量**（未知 / 高阻）；大写 `X` / `Z` 是普通符号。
- v1.0 不做时间/频率换算：数值后**不能**跟单位（`1.5ns`、`800MHz` 都视为非法）。
- 值的比较按**类型 + 规范形文本** 执行：`32'h1` 与 `1` 不是同一个值，`8'h2a` 与 `8'h2A` 是。

### 文件骨架

```chiperf
chiperf 1.0                       # 版本行：写入者必须写，且在首行
@meta design="rv32i-core" tool="verilator" date="2026-09-15"

[clk] p                           # 从这里开始才是事件
[cnt] "core.retired"
@end                              # 正常结束标记（非必须，缺少时会被判为"可能被截断"）
```

## 事件选型

| 我想表达                           | 用它            | 为什么不是别的                                     |
| ---------------------------------- | --------------- | -------------------------------------------------- |
| "此刻发生了第 N 次"                | [`cnt`](cnt.md) | [`evt`](evt.md) 不累加；[`val`](val.md) 是保持型   |
| "这一刻发生了一件事，附带一个载荷" | [`evt`](evt.md) | [`cnt`](cnt.md) 的载荷位置是增量，语义不同         |
| "这个信号/指标现在是多少"          | [`val`](val.md) | 保持型，只写变化点即可                             |
| "这一级现在装着什么"               | [`pip`](pip.md) | 多出"条目/气泡/驻留"这层语义；[`val`](val.md) 没有 |
| "状态机现在在哪个状态"             | [`fsm`](fsm.md) | 多出跳转表、自环、驻留统计                         |
| "给人看的一句话"                   | [`msg`](msg.md) | 不参与任何派生量                                   |
| "推进时钟"                         | [`clk`](clk.md) | 只有它能推进周期号（`at=` 只是覆盖单条记录的位置） |
| "把之前的记录丢掉"                 | [`rst`](rst.md) | 控制记录，不是事件                                 |

## 常见写法模板

### 时钟双边沿

```chiperf
[clk] p
[val] "core.if.pc", 32'h8000_0000
[cnt] "core.icache.access"
[pip] "core.if", 0x80000000
[clk] n
```

### 时钟上升沿（常用）

```chiperf
[clk] p
[cnt] "core.retired"
[clk] p
[cnt] "core.retired", 2
```

### 基于 `at` 指定时序

> 这是针对从其他格式转为 Chiperf 的情形设计的

```chiperf
[val] "core.if.pc", 32'h8000_0000, at=1p
[cnt] "core.retired", at=1p
[val] "core.if.pc", 32'h8000_0004, at=2p
[cnt] "core.retired", at=2p
```

### 计数器置位

```chiperf
[cnt] "core.l2.access", abs=1024, at=1000p
[cnt] "core.l2.hit", abs=880, at=1000p
[cnt] "core.l2.access", abs=2048, at=2000p     # 相邻两次 abs= 相减就是区间增量
[cnt] "core.l2.hit", abs=1720, at=2000p        # 命中率：两个区间差相除，不要另写一条 val
```

### 异步到达

```chiperf
[clk] p
[val] "core.irq.level", 0
[clk] n
[evt] "irq.assert", 7, async=1           # 不在一根沿上，画在周期区间内部
[cnt] "core.instr", async=1
```

### 复位

```chiperf
[evt] "I'll be discarded"
[rst]                                    # 之前的热身数据整批丢弃
[clk] p
[cnt] "core.retired"
```

### 一条贯通流水线的指令

```chiperf
[pip] "core.if",  0x80000000
[pip] "core.id",  0x80000000     # 同一个值 ⇒ 可视化同色，顺着颜色能跟到写回
[pip] "core.ex",  0x80000000
[pip] "core.mem", 0x80000000
[pip] "core.wb",  0x80000000
[clk] p
[pip] "core.wb",  bubble         # 写回完成，该级空了
```
