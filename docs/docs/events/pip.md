# `pip` 流水级 / 缓冲 / 通道

指定一个流水级当前的状态。

## 语法

```chiperf
[pip] <名称> , ( <值> | bubble ) , [ <属性> ]
```

EBNF 表达式: 
```ebnf
pip = "pip" , <名称> , ( <值> | "bubble" ) [ , <属性> ] ;
```


## 参数

| 参数     | 类型                | 必需 | 说明                            |
| -------- | ------------------- | ---- | ------------------------------- |
| `<名称>` | `sym`/`str`         | 是   | 流水级名称                      |
| `<值>`   | 任意标量 / `bubble` | 是   | 当前内含的值；`bubble` 表示气泡 |


## 解释

`pip` 适用于记录流水线的状态，以分析其中气泡的分布与影响。

`pip` 是 **保持型** 事件，即: 在一次 `pip` 记录后，若后续时钟周期没有出现同名记录，则认为该流水级保持当前状态。  

对于使用 `reg` 保持状态的流水级，可以直接抓取状态作为 `pip` 记录；对于使用 `ready`-`valid` 握手的流水级，则需要在 RTL 层增加用于仿真的状态保持逻辑。

## 示例

```chiperf
[pip] "core.if", 0x1234abcd     # IF 开始持有这条内容
[pip] "core.id", 0x1234abcd     # 它到了 ID；IF 那条不动（要保持就什么都不写）
[pip] "core.if", bubble         # IF 空了（取指停顿；冲刷/取消也这么表达）
[pip] "core.mem", x             # 有内容但内容未知
```
