# `fsm` 状态机

记录状态机的当前状态。  

## 语法

```chiperf
[fsm] <名字> , <状态> [ ，<属性> ]
```

EBNF 表达式: 
```ebnf
fsm = "fsm" , <名字> , <状态> , [ <属性> ];
```


## 参数

| 参数     | 类型                  | 必需 | 说明                     |
| -------- | --------------------- | ---- | ------------------------ |
| `<名字>` | `sym`/`str`           | 是   | 状态机名，如 `core.ctrl` |
| `<状态>` | `sym` / `str` / `int` | 是   | 当前状态                 |


## 解释

`fsm` 适用于记录一个状态机的状态转移过程。

`fsm` 是 **保持型** 事件，即: 在一次 `fsm` 记录后，若后续时钟周期没有出现同名记录，则认为该状态机保持当前状态。

解析器通过 `fsm` 的变化解析出**状态转移图**，以及各个状态与状态转移发生的频率。  
相邻两条记录的状态相同（`from == to`）时记为一次**自环**：保持型语义下"状态未变但被再次上报"是正常写法，**不会**产生任何诊断。


## 示例

```chiperf
[fsm] "core.ctrl", IDLE
[fsm] "core.ctrl", FETCH
[fsm] "core.ctrl", FETCH        # 自环：正常写法，不是警告（可视化合并成一段驻留）
[fsm] "core.icache.ctrl", 3     # 状态也可以是数字或字符串
```
