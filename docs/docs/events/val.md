# `val` 数值采样

把某个信号的当前取值记下来；此后**一直保持**，直到下一次采样。

```ebnf
val = "val" , <名字> , <值> ;
```

| 参数 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| 1 | 名字 | 是 | 数值名（建议层级路径，如 `core.if.pc`） |
| 2 | 任意标量 | 是 | 采样到的取值 |

**语义**：**保持型**。首个采样之前的值是"未知"；任意两次采样之间保持前一次的取值。

**什么时候用**：任何"这一拍这个信号是什么"的量 —— PC、指令字、命中率、温度、队列水位。
它刻意**只记变化点**：值没变就不用写（保持型替你省掉了重复行）。

```chiperf
[val] "core.if.pc", 32'h8000_01d0
[val] "core.id.instr", "addi a0,a0,1"    # 字符串值：反汇编文本、状态名
[val] "core.l1d.way", 4'b10xz            # 4 态：含有未知位/高阻位
[val] "core.ipc", 1.25                   # 实数
[val] "vdd", 0.95
```

⚠️ 想让可视化画出"每周期都在变"的阶梯，**不需要**每拍写一条；写出变化点即可，其余靠保持。
⚠️ `x`/`z` 参与比较：已知 → 未知、未知 → 已知都算"变化"。
⚠️ 想要"某个**事件**带一个载荷"（中断号、请求 ID）用 `evt`，不要用 `val`。
