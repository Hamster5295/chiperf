# `val` 数值采样

记录信号取值。  

## 语法

```chiperf
[val] <名字> , <值> , [ <属性> ]
```

EBNF 表达式: 
```ebnf
val = "val" , <名字> , <值> [ , <属性> ] ;
```


## 参数

| 参数     | 类型        | 必需 | 说明         |
| -------- | ----------- | ---- | ------------ |
| `<名字>` | `sym`/`str` | 是   | 数值名       |
| `<值>`   | 任意标量    | 是   | 采样到的取值 |


## 解释

`val` 适用于记录一些变化量，如 `pc`, 栈顶，队列占用情况等。

`val` 是 **保持型** 事件，即: 在一次 `val` 记录后，若后续时钟周期没有出现同名记录，则认为该数值保持不变。  

## 示例

```chiperf
[val] "core.if.pc", 32'h8000_01d0
[val] "core.id.instr", "addi a0,a0,1"    # 字符串值：反汇编文本、状态名
[val] "core.l1d.way", 4'b10xz            # 4 态：含有未知位/高阻位
[val] "core.ipc", 1.25                   # 实数
[val] "vdd", 0.95
```
