# `clk` 时钟沿

推进周期计数。  

## 语法

```chiperf
[clk] <边沿>
```

EBNF 表达式: 
```ebnf
clk = "clk" , <边沿> ;
<边沿> ∈ { "p" , "n" }
```


## 参数

| 参数     | 类型  | 必需 | 说明                                  |
| -------- | ----- | ---- | ------------------------------------- |
| `<边沿>` | `sym` | 是   | `p` 上升沿 / `n` 下降沿（大小写敏感） |


## 解释

`clk` 让全局时钟 `clock` 向后推进。

对于常见的上升沿敏感设计中，`[clk] p` 即可表征一次时钟上升沿。  
在该事件 **之后** 触发的其他事件被视为是 **该时钟周期** 触发的

对于仅上升沿触发的系统，只需要记录 `[clk] p`，由可视化自动补全时钟下降沿（渲染推断，不写回数据）。


若系统存在下降沿敏感，则可使用 `[clk] n` 表征一次下降沿。  
在该事件 **之后** 触发的其他事件被视为是 **该时钟周期的下降沿** 触发的


> [!WARNING]
> 每一个周期中，`clk` 事件必须是第一个触发的。若有其他事件早于 `clk`, 则会被视为上个时钟沿。
> 
> 考虑到不同仿真器对 `always` 块的执行顺序不同，**不推荐**将记录事件的 RTL 仿真函数散布在源代码各处，而是应当集中在同一个 always 块中实现。


## 示例

```chiperf
[clk] p                      # 第 1 个上升沿（周期 1）
[cnt] "core.retired"         # 这一拍发生的事，跟着上面那条沿
[clk] n                      # 同一周期的下半段，非必须
[clk] p                      # 第 2 个上升沿（周期 2）
```
