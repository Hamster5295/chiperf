# `evt` 瞬时事件

记录一次瞬时事件的发生


## 语法

```chiperf
[evt] <名字> [ , <载荷> ] [ , <属性> ]
```

EBNF 表达式: 
```ebnf
evt = "evt" , <名字> , [ <载荷> ] , [ <属性> ];
```


## 参数

| 参数     | 类型        | 必需 | 说明                           |
| -------- | ----------- | ---- | ------------------------------ |
| `<名字>` | `sym`/`str` | 是   | 事件名                         |
| `<载荷>` | 任意标量    | 否   | 载荷（中断号、请求 ID、地址…） |


## 解释

`evt` 适用于描述瞬时事件，关注其发生的频率与分布，如分支预测成败、同步中断 / 异常等。

如需关注某个事件在执行过程中的累计，请使用 [`cnt`](cnt)。


> [!WARNING]
> `<名字>` 应当始终保持不变，`evt` 不关心其值的变化


## 示例

```chiperf
[evt] "core.redirect", 0x80000100          # 带载荷：跳到哪里
[evt] "irq.assert", 7, async=1             # 异步到达：画在两个沿之间
[evt] "reset.released"
[evt] "tlb.way", 2, note="demand miss"     # 注解放在 note=，不要拼进名字
```
