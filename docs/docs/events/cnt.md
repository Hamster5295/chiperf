# `cnt` 计数器

将指定计数器累加一次。


## 语法

```chiperf
[cnt] <名字> [ , <增量> ] [ , <属性> ]
```

EBNF 表达式: 
```ebnf
cnt = "cnt" , <名字> , [ <增量> ] , [ <属性> ];
<增量> = int ;
```


## 参数

| 参数     | 类型        | 必需 | 说明                          |
| -------- | ----------- | ---- | ----------------------------- |
| `<名字>` | `sym`/`str` | 是   | 计数器名                      |
| `<增量>` | `int`       | 否   | 增量，缺省 `+1`，**可以为负** |


## 属性

| 属性  | 值类型 | 说明                                              |
| ----- | ------ | ------------------------------------------------- |
| `abs` | `int`  | **绝对值设置**：把累计值直接置为它（不贡献增量） |


## 解释

`cnt` 适用于记录一个递增的数值，而不关心其发生的次数 / 频率，如记录指令退休数量等。  
部分特殊计数器需要在过程中置位成指定数值，可使用 `abs=xxx` 实现。  

`cnt` 可以通过指定增量为 **负数** 实现递减。

如果需要观测一个值出现的频率，请使用 [`evt`](evt)。


> [!WARNING]
> 同一个名字只对应一条计数器轨迹；v1.0 没有时钟域，同名即同一个计数器。
> 但与其它类型（`val`/`fsm`/`evt`/`pip`）同名时是**不同轨道**：轨道按 `(事件类型, 名字)` 区分，不会冲突也不会被改名。


## 示例

```chiperf
[cnt] "core.retired"                 # +1
[cnt] "core.retired", 4              # 一条指令退休了 4 次？不会 —— 这是"一次 +4"（例如 4 发射）
[cnt] "core.stall.mem", -1           # 允许负增量
[cnt] "core.cycles", abs=1234567     # 硬件计数器回读：总量置为 1234567
```
